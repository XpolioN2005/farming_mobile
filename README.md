# 🌾 Farming Automation Prototype

**Status:** Prototype (No longer in active development)
**Engine:** Godot 4.4
**Developer:** XpolioN

---

## 📖 Overview

This project started as an experiment exploring the question:

> “What if _Stardew Valley_ met _Factorio_?”

The goal was to create a cozy, automated farming experience where players manage **helpers** who perform all the work — farming, harvesting, and processing — while the player observes and optimizes.

Over time, this project evolved into a **prototype for character AI behavior** and **performance testing** in Godot.

---

## ⚙️ Prototype Focus

- **AI System:** Modular worker state machine for behaviors like Idle, Wander, Work, and Dragging.
- **Interaction:** Player can pick up and drag helpers to assign tasks.
- **Stress Test:** Includes a worker count slider to test scalability and performance under load.

---

## 🎮 Gameplay Concept (Original Loop)

1. **Assign Helpers** – Drag helpers to tasks such as farming or harvesting.
2. **Observe** – Watch them interact and perform autonomously.
3. **Collect & Profit** – Resources are gathered and converted into income.
4. **Upgrade & Optimize** – Use profits to unlock new features or efficiency upgrades.
5. **Repeat & Expand** – Gradually scale your operation and compete in crop contests.

While this loop worked conceptually, it lacked depth for a full game — so it remains as a **proof of concept prototype**.

---

## 🎨 Art Style

Initially planned as vector-based, the visual direction shifted to **Hana Caraka’s pixel style**, which perfectly matched the cozy, minimal farming atmosphere.
